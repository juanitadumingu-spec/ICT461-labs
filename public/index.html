About your saved preference

Your last chosen programme is remembered in localStorage so the dropdown pre-fills next time you open this page — even after closing the browser entirely. sessionStorage would behave differently: it would be cleared as soon as this browser tab is closed, and it is never shared between tabs even on the same page. Nothing else you type is stored.

About this build

The interface runs on http://localhost:5500 and talks to a separate Express API on http://localhost:3000. Every write (register, update, delete) is validated again on the server, independently of anything this page checks first — open DevTools, submit a request that bypasses this form, and the API still rejects invalid data.
